## Project Overview

fantastic-potato is a deliberately small static HTML project containing a basic homepage with French-language text. It can serve as the foundation for a personal website, a first web project, or a minimal online profile.

The project keeps its page structure and markup intentionally simple. With only a single-page layout to work through, the files are easy to understand, modify, and reuse for learning, quick prototypes, or small homepage concepts.

## Using the Page

Preview the homepage by opening its primary HTML file locally. The text can then be replaced with your own content, including the document title, heading, and paragraphs.

A typical editing cycle looks like this:

1. Replace the included text with French, multilingual, or other content of your choice.

3. Save the HTML and reload the browser preview.
4. Publish the updated files to your hosting service when the page is ready.

## Page Configuration

There is no separate configuration layer in this project. Page options and content are written directly in the HTML, including the language declaration, browser title, and text shown to visitors.

Example structure:

    <!DOCTYPE html>
    <html lang="fr">
    <head>
      <meta charset="UTF-8">
      <title>Mon premier site</title>
    </head>
    <body>
      <h1>Bienvenue sur mon site !</h1>
      <p>Ceci est ma première page web.</p>
    </body>
    </html>

Edit the existing wording or extend the document with additional sections and layout elements as your site grows.
